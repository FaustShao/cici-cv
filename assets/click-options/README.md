# Click audition samples

Original creator: Kenney, Interface Sounds 1.0, CC0.
Source: https://kenney.nl/assets/interface-sounds
Downloaded unchanged Ogg originals from https://github.com/hipdiscovery/Free-Sound-Effects/tree/master/audio/kenney-interface (see the bundled license).

Options: 1 = click_001, 2 = click_002, 3 = click_004, 4 = click_005.
Converted to mono MP3; peaks matched to -9.1 dBFS to compare timbres at similar levels. Preview files contain the same click three times with half-second gaps. The site uses option 4 at volume 0.4. `4-single.pcm.json` contains the 171 signed 16-bit mono samples decoded from `4-single.mp3` at its native 24 kHz. The sample data is bundled with the controls so the first press needs no fetch or audio decoding.
