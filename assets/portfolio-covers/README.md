# Portfolio display covers

User-supplied covers, visually matched by their titles:

1. Tideline: `A4 - 2.png.zip`
2. SafePaw Family: `A4 - 3.png.zip`
3. DREAM SENTINEL: `A4 - 4.png.zip`
4. Future Gazette: `A4 - 1.png.zip`

All originals are 5176 × 2800. WebP display copies are scaled proportionally to cover the 2560 × 1440 display, with a small centered horizontal crop to fill the 16:9 model screen without white bands. These replace preview covers only; project documents are unchanged. The versioned filenames also prevent cached old covers from appearing after deployment. Matching files under the 3D application's public/projects/images directory serve its native texture loader.
